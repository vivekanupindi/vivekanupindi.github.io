# Vivek Anupindi — Research Portfolio

A responsive, Netflix-inspired research portfolio built with plain HTML, CSS, and JavaScript. No framework, build step, or backend is required.

## Files

- `index.html` — page structure and portfolio content.
- `css/styles.css` — responsive layout, themes, card rails, and visual styling.
- `js/main.js` — mobile navigation, theme toggle, horizontal rail controls, and research-detail dialogs.
- `assets/Vivek_Anupindi_CV.pdf` — CV linked from the home page.
- `assets/favicon.svg` — lightweight monogram favicon for browser tabs.

## Preview locally

1. Keep the folder structure intact.
2. Open `index.html` in a modern browser. For a closer match to web hosting, run a simple local static server from this folder, e.g. `python -m http.server 8000`, then visit `http://localhost:8000`.
3. The Google Fonts import requires internet access; the page falls back to system fonts if unavailable.

## Publish with GitHub Pages

1. Create or open the repository for `vivekanupindi.github.io`.
2. Upload the contents of this folder to the repository root (so `index.html` is at the root, not nested inside another folder).
3. Commit and push to the branch configured for GitHub Pages.
4. In repository Settings → Pages, confirm the source branch and root folder if needed.
5. Visit `https://vivekanupindi.github.io/` after deployment finishes.

## Portfolio structure

The design is Netflix-inspired rather than a direct Netflix clone: dark cinematic styling, horizontal research-card rails, and expandable project details, adapted for an academic portfolio. The website uses plain HTML, CSS, and JavaScript; there is no backend or framework dependency.
